## Installation
You can clone this repository wherever you want.

### Windows
Run the following commands in Windows PowerShell.
```powershell
git clone https://github.com/hideaki-hayamizu/dotfiles.git ; cd dotfiles ; powershell -NoProfile -ExecutionPolicy Bypass -File "bootstrap.ps1"
```
